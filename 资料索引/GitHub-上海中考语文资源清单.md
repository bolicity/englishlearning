## 核心判断

**1. 上海中考语文的真正"考纲级"资源，GitHub 基本没有。**
150 文言实词、名著篇目、默写篇目这些地方性考纲，开源社区几乎无人整理。命中率远低于数学——数学还能翻到上海一模二模卷，语文只有 2–3 个 ★0 的零散库。

**2. 最值得动手的是这三个：**

| 仓库 | 为什么 |
|---|---|
| `mylukin/shici` | **唯一**直击"上海中考 150 文言文实词"的资源，含音频 |
| `ichangting/taotao-skills` | ★12、MIT、2026-07 仍在更新，12 个初中语文教学技能，**方法论价值 > 内容价值** |
| `wwq0327/gist-shuihu` | CC-BY-SA-4.0 的**名著伴读结构化范式**（487 卡片 + schema），可照搬到儒林外史 |

**3. 与本站的衔接点：**
你的 `chinese/` 已有儒林外史四页 + 名著题目条带。`gist-shuihu` 的"互链卡片 + schema"结构，
和你现在手工搭的连环画/矩阵是同一思路——如果想把这套做法**系统化、可扩展到其他名著**，它是最值得拆解的样板。
