一、上海国际高中格局总览
三类办学性质 · 沪上国际化教育生态
先分清三条赛道。上海做国际课程的高中大致分三类：① 公办高中国际课程班（10 所，仅招上海生源、凭中考录取）；② 民办普通高中国际课程班（10 所，可招本地＋外地生源）；③ 中外合作办学（仅七宝德怀特 1 所）。前两类加上中外合作，就是家长口中的官方 「21 所」——最大价值是可保留国内高中学籍，理论上「两条腿走路」。此外还有大量民办双语 / 国际高中（100 所以上）与外籍人员子女学校（39 所），均不在此名单内。
「21 所」的学籍不是白给的——它有法定对价。按上海市教委规定，国际课程班学生须参加本市学业水平合格性考试的思想政治、语文、历史、地理四科且成绩合格，才能申请高中毕业证书。所以「21 所」的三年里必然含这四门国家课程与四科合格考，课时要从国际课程里让出来。这不是学校加了负担，而是学籍与毕业证的价格。

这决定了三条赛道的真正取舍：要学籍兜底（可高考 / 综评、双文凭）→ 选「21 所」，接受四门国家课程占课时；纯冲海外、尤其英联邦 / 牛剑 → 选光华剑桥、领科这类无国家课程的民办国际高中，时间密度更高，代价是无国内学籍、不能参加高考。

特别澄清：申请境外高校（含中国香港）并不需要国内学籍。港校全部受理 A-Level / IB / AP 成绩直接申请（国际课程通道，不依赖高考），英美加澳同理。学籍的唯一实质意义是保留高考 / 综评这条内地退路——「香港方向」本身不是要学籍的理由，除非打算用高考成绩去申港校。

A-Level 优质校分层推荐

Ⅰ

第一梯队 · 牛剑 / G5 稳定输出（IB＋A-Level 双强）

上海市世外中学：2025 届 IB / A-Level 共斩获 12 枚牛剑（牛津 4 ＋ 剑桥 8），G5 录取 81 枚，英本方向 72% 至少一份 G5。 上海市民办平和学校：2023 年开设 A-Level，2025 届 11 枚藤校 ＋ 6 枚剑桥，约 99% 获美本前 60。两校为「21 所」A-Level 的天花板，入学门槛与竞争强度也最高。

Ⅱ

第二梯队 · 课程成熟、升学亮眼

七宝德怀特：唯一中外合作，IBDP ＋ A-Level 可获中美双文凭，2026 届 11 国 1086 封录取、60% 全球前 30。 尚德实验：2025 年首届 A-Level 全球统考 40% 拿下 AS 全 A，物理 / 生物 / 进阶数学 70% 达 A–A*。 文来中学：英国考试局授权 A-Level 考试中心 ＋ Cognia 认证 ＋ 五星雅思示范校，A-Level 小班精细（专项页）。

Ⅲ

第三梯队 · 新开通道，方向明确时值得考虑

协和双语高中（古北）：2027 学年起两年制 A-Level，只开数学 / 进阶数学 / 物理 / 经济，适合理工科特长突出、目标极明确的学生。 西南位育：2026 年 9 月起新增 A-Level，与美高 AP 构成「双 A 体系」，留学方向未定时弹性最大。 西外外国语：A-Level ＋ 美高 AP ＋ 日高，约 11 万 / 年，是 21 所中门槛与费用最低的 A-Level 路径。

提醒：「21 所」入读需双达标——先通过学校自主选拔拿到预录取，再参加上海中考并达到该校录取分数线，缺一不可。选择 A-Level 通道还要留意：协和、西南位育的 A-Level 均为 2026/2027 学年新设，尚无毕业生数据，首几届的师资与出分稳定性需重点考察。

五、主流课程体系对照
出口方向决定课程选择

A-Level 英联邦

英国普通中等教育高级水平课程，学术深度高、可自由选 3–4 门，适合偏科、目标英国 G5（牛剑）的学生。上海体系成熟，代表校：领科、光华剑桥、赫贤、阿德科特。

IBDP 全球

国际文凭大学预科项目，六大学科组＋三大核心（认识论 / 专题论文 / CAS），全人教育、文理兼修，认可度最广但课业最重。上海约 30 所学校开设。代表校：包玉刚、平和、世外。

美高＋AP 美国

美国高中课程＋大学先修课程，可换算大学学分，灵活度高，适合目标美国名校的学生。代表校：星河湾、WLSA、诺美、西外。

加拿大 BC / OSSD 加拿大

加拿大 BC 省或安大略省体系，过程性评价为主、考试压力小，可直升加拿大及英澳高校。代表校：枫叶、燎原。

澳洲 WACE / VCE 澳洲

西澳 / 维州高中证书课程，可直申澳洲八大，也可作英美申请的补充成绩。代表校：天华英澳美等。

日本 EJU 课程 日本

面向日本留学，含日语＋留考（EJU）＋校内考辅导。学费门槛低、文化适应快，近年快速扩张。代表校：文来日高部、朝阳义塾、尚德。

香港 DSE / 新加坡 中国香港 / 新加坡

香港中学文凭考试，可申请中国香港高校及海外；新加坡方向亦有专门课程。代表校：耀中（外籍）、常青藤等。

德国 / 法国 / 欧洲 欧洲

DSD（德语）、Abitur、法国高中文凭等，多语种小语种路线，适合有明确欧洲留学规划的家庭。代表校：曹杨二中、法国外籍学校、德国外籍学校。

七、择校七个关键点
先定出口，再定课程，最后定学校
1

先确认「要学籍还是要时间」

「21 所」的国内学籍有法定对价：须通过语、政、史、地四科合格考才能拿上海高中毕业证，这四门课会占去课时。要学籍兜底（可高考 / 综评）就选「21 所」；纯冲海外、只要 A-Level 出分效率，就选无国家课程的民办国际高中（如光华剑桥、领科），但无国内学籍、不能高考。

2

户籍 / 国籍是第一道硬门槛

公办国际课程班仅招上海生源；外籍人员子女学校仅招外籍 / 港澳台；民办双语与国际高中一般不限户籍，但名额与要求各校自定。

3

用留学方向倒推课程体系

冲英国 → A-Level；美国名校且全科均衡 → IB 或美高 AP；加拿大 / 澳洲 → BC / OSSD / VCE；日本 → 日高 EJU；中国香港 → DSE。课程错配比学校普通更致命。

4

看升学数据，更要看「分母」

绝大多数学校宣传的都是「TOP30 录取率」，务必问清年级总人数、实际申请人数与录取分布，避免用少数牛剑 / 藤校案例代表全校水平。

5

师资稳定性与中外教比

重点关注学科教师是否为全职、外教流动率、是否有 IB 考官 / 剑桥培训资质。频繁换老师对 A-Level / IB 两年制课程伤害极大。

6

「双轨制」实操上很难

即便在「21 所」拿到双学籍，国际课程的大考（托福 / 雅思 / AP / A-Level）与国内合格考同时压上，学生基本忙不过来——对国际课程班而言，语、政、史、地四科合格考是拿毕业证的必要条件，绕不开。想走国际路线，就别指望真正两全。

7

实地看校＋问在校家庭

榜单（胡润 / 福布斯 / 京领 / HKPEP）只作参考，各榜口径不同。真正的信息在开放日的课堂氛围、宿舍与餐厅，以及在校家长的长期反馈。

8.4 全市 A-Level 优质校速览（中国籍可选）

冲

冲牛剑 / G5 首选（头部梯队）

稳

稳步冲 G5 / 王爱曼华（强势梯队）

上实剑桥、圣华紫竹、光华启迪、阿德科特、赫贤、WLSA（AL）均有稳定的 G5 预录取数据，适合中等偏上学术水平、目标 QS 前 100 的学生；七德、尚德、文来适合想同时保留国内学籍的家庭。

保

保底与特色方向（特色 / 入门）

预算敏感或方向多元时，可看金苹果、常青藤、东鼎、天华英澳美、美达菲、新纪元等「A-Level ＋ 其他课程」组合校；UEC、科桥、浦华曜、籽奥、莱克顿则是纯 A-Level 小校，规模小、管理细，但升学数据体量有限，务必实地考察师资与历史出分。
